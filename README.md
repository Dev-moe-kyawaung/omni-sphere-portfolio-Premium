# Moe Kyaw Aung | Premium Portfolio

A premium, dark-first, glassmorphism developer portfolio focused on clear value, 3 flagship projects, case studies, and easy contact.

## Features
- Hero section with strong positioning
- 3 flagship projects
- Case studies
- Skills and about sections
- Contact CTA
- Theme toggle
- Mobile menu
- Lightweight AI assistant

## Tech Stack
- HTML
- CSS
- JavaScript

## Run Locally
Open `index.html` in a browser or use a simple static server.

## Deploy
### GitHub Pages
Use GitHub Actions and deploy the repository as a static site.

### GitLab Pages
Use `.gitlab-ci.yml` and publish the static output from `public/`.
